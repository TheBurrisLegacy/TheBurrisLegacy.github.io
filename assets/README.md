# Assets

The **assets** directory contains the shared resources used throughout **The Burris Legacy** website.

These files provide the visual identity and supporting resources that help present the public face of the Burris Legacy while keeping the website organized and maintainable.

## Purpose

The assets directory may include:

* Logos
* Icons
* Favicons
* Fonts
* Documents
* Downloadable resources
* Shared media used across multiple pages

Assets are intended to be reusable and independent of any single webpage.

## Organization

```
assets/
├── documents/
├── favicon/
├── fonts/
├── icons/
├── logos/
└── media/
```

Subdirectories may be expanded as the website grows.

## Philosophy

The Burris Legacy website serves as the public entrance to a larger effort dedicated to preserving the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.

Every asset contributes to presenting that legacy with clarity, consistency, and permanence.
