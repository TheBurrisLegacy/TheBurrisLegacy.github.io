# JavaScript

The **js** directory contains the JavaScript files used throughout **The Burris Legacy** website.

These scripts provide interactive functionality while preserving the website's primary goals of simplicity, accessibility, and long-term maintainability.

## Purpose

The JavaScript directory stores code responsible for enhancing the visitor experience without becoming dependent upon complex frameworks or unnecessary technologies.

Typical functionality may include:

* Navigation
* Menus
* Theme controls
* Image galleries
* Lightbox displays
* Search
* Forms
* Page enhancements
* Accessibility improvements

## Organization

```text
js/
├── main.js
├── navigation.js
├── gallery.js
├── search.js
└── utilities.js
```

Files may be consolidated or expanded as the website evolves.

## Design Principles

JavaScript should:

* Enhance, not replace, standard HTML.
* Remain lightweight and efficient.
* Be well documented.
* Follow modern web standards.
* Preserve compatibility across common browsers.
* Degrade gracefully when JavaScript is unavailable whenever practical.

## Philosophy

The Burris Legacy exists to preserve the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.

Technology should support that mission quietly and reliably, allowing the legacy itself to remain the focus.
