# CNAME

This directory preserves the custom domain configuration for **The Burris Legacy** website.

## Purpose

The `CNAME` file connects the GitHub Pages repository to the public domain:

**https://burrislegacy.com**

This allows visitors to access the website through its permanent public address while the site itself is hosted from GitHub Pages.

## Current Domain

* **Primary:** burrislegacy.com
* **Provider:** GitHub Pages
* **Registrar:** GoDaddy
* **Email:** Proton Mail

## Philosophy

The domain is more than an address. It serves as the permanent public entrance to **The Burris Legacy**, while the repositories preserve the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.
