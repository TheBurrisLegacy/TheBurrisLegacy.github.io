# Images

The **images** directory contains the visual resources used throughout **The Burris Legacy** website.

These images communicate the identity, history, and purpose of the Burris Legacy while supporting the presentation of its public website.

## Purpose

The images directory stores graphics and photographs that are referenced by one or more webpages.

Typical contents include:

* Logos
* Banners
* Background images
* Icons
* Family photographs (when appropriate)
* Illustrations
* Symbols and emblems
* Website graphics

## Organization

```text
images/
├── backgrounds/
├── banners/
├── icons/
├── logos/
├── people/
├── symbols/
└── website/
```

Subdirectories may be expanded as additional visual assets are developed.

## Image Standards

Whenever practical, images should be:

* High resolution
* Optimized for web delivery
* Properly licensed or original
* Clearly named
* Stored in appropriate formats (PNG, SVG, JPG, WebP)

The Burris Legacy emblem serves as the primary visual identity of the website.

## Philosophy

Every image should reinforce the mission of preserving the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.

Visuals should support the legacy—not distract from it.
