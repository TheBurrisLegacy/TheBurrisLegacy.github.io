# The Burris Legacy

Welcome to the official website repository for **The Burris Legacy**.

This repository contains the source code, assets, and public-facing content for **burrislegacy.com**.

## Purpose

The Burris Legacy exists to preserve the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.
