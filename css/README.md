# CSS

The **css** directory contains the Cascading Style Sheets (CSS) used throughout **The Burris Legacy** website.

These styles define the visual presentation, layout, typography, colors, spacing, and responsive behavior of the website while maintaining a consistent identity across all public pages.

## Purpose

The CSS directory exists to separate presentation from content, allowing the website to remain organized, maintainable, and scalable as it grows.

## Typical Contents

```text
css/
├── style.css
├── layout.css
├── navigation.css
├── typography.css
├── responsive.css
└── print.css
```

Individual stylesheets may be consolidated or expanded as the website evolves.

## Design Principles

The visual design of **The Burris Legacy** emphasizes:

* Simplicity
* Readability
* Timelessness
* Accessibility
* Consistency

The website is intended to feel like a carefully preserved archive rather than a commercial website.

## Philosophy

Every page should support the mission of preserving the records, stories, responsibilities, and treasures entrusted from one generation of the Burris family to the next.

The presentation should never distract from the legacy it exists to preserve.
